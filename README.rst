KINESIS Core Technology Platform Wiki
=====================================

This repository is the generated public source for the KINESIS Core Technology Platform Lab Wiki
at New York University Abu Dhabi. The rendered documentation is available at
`rtd-kinesis.readthedocs.io <https://rtd-kinesis.readthedocs.io/>`_.

About the Wiki
--------------

The wiki is the central public reference for KINESIS facilities, equipment, technical
capabilities, computing resources, safety guidance, and research output. It helps researchers
understand the platform, identify resources for their work, and acknowledge the facilities and
equipment that supported their publications.

The documentation is continuously maintained as KINESIS capabilities, equipment, and guidance
evolve. Corrections and useful additions are welcome.

Generated Repository
--------------------

``KinesisCTP/rtd-kinesis`` is a sanitized, generated mirror. Its files are published
deterministically from the canonical private documentation repository after private pages,
operational material, internal identifiers, and controlled assets are removed. Do not edit this
repository directly or open pull requests against generated files.

KINESIS GitHub Organization
---------------------------

The `KINESIS CTP GitHub organization <https://github.com/KinesisCTP>`_ hosts public development
workspaces for equipment-focused software, ROS packages, examples, tools, and related technical
resources. Repository availability does not imply a common software license; consult each
workspace for its own terms.
