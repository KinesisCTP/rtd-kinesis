==================
Linux Workstation
==================

.. figure:: ../../_static/images/workstation-linux.jpg
   :alt: Linux Workstation
   :width: 60%
   :align: center

   Linux Workstation

A custom-built, high-performance Linux workstation available for research and development. It is located at the Vicon Command Center and accessible via the KVM switch shared with the Vicon PC and DGX Spark.

Purpose
-------

This workstation is suitable for:

- Software development and testing
- Data processing and analysis
- Simulation and modeling
- ROS development and robot software integration
- General computational tasks

Hardware Specifications
-----------------------

.. list-table::
   :widths: 30 70
   :header-rows: 0

   * - **CPU**
     - AMD Ryzen 9 7950X3D — 16 cores, 32 threads
   * - **Motherboard**
     - ASUS ROG Crosshair Hero DDR5 X670E (AMD Ryzen 7000 series)
   * - **RAM**
     - 96 GB DDR5-6000 MHz (Corsair 48×2, CMH96GX5M2B)
   * - **Storage**
     - 2 TB M.2 NVMe SSD — Samsung 990 Pro (7,450/6,900 MB/s)
   * - **GPU**
     - ASUS ROG STRIX NVIDIA RTX 4090 — 24 GB GDDR6X
   * - **Case**
     - NZXT H7 Flow (2024), RGB
   * - **CPU Cooler**
     - NZXT Kraken Elite 360mm RGB LCD (AIO liquid cooler)
   * - **PSU**
     - NZXT C1200 — 80 Plus Gold, Fully Modular, PCIe 5.0

Software Environment
--------------------

- **Operating System:** Ubuntu (Linux)
- ROS / ROS 2
- Standard development tools (Python, C++, Git, Docker, etc.)

Usage Guidelines
----------------

- Schedule usage for extended computational tasks
- Clean up temporary files after use
- Respect other users' data and processes
- Report any issues to lab administrators
