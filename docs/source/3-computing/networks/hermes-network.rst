==============
Hermes Network
==============

The Hermes Network is a dedicated wireless network for the KINESIS CTP Arena, designed specifically to support motion capture operations and real-time robot/drone communications.

Purpose
-------

Hermes provides:

- Low-latency wireless connectivity for robots and drones operating in the Arena
- Real-time position data broadcast from the Vicon PC to all devices on the network
- Control link for researcher laptops sending commands to robots/drones
- Isolation from the main KINESIS CTP network to reduce interference during experiments

Security Notes
--------------

- Hermes is physically and logically isolated from the NYUAD campus network
- Only authorized lab devices and users should connect
- Contact lab administrators for access credentials
